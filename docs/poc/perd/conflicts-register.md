# PERD conflicts register

> **Status changes only through a decision record.** A status here moves only when a record in [`docs/decisions/`](../../decisions/README.md) decides it, in the same pull request (AGENT-29). Where the resolution needs a SoT edit, that edit lands in the same pull request too.

Source: [`NOEMA_POC_PERD_v1.1.md`](NOEMA_POC_PERD_v1.1.md) §72, lines 5883–5911. The first five columns are copied verbatim; only the `Status` column is added. "SoT §" references are to the [Source of Truth](../../NOEMA_SOURCE_OF_TRUTH.md); bare "§" references are to the PERD. The SoT v1.3 wins every conflict (PERD P.1, §72 rule).

Status values:

- **Resolved by SoT**: the SoT already decides the point, and the PERD follows it. Nothing to decide.
- **Open**: needs a decision record (and, where stated, a SoT edit) before the PERD's minimum resolution is binding. Until then, apply the safer reading (AGENT-20).
