# Daily notes

One note per working day, written after the 17:00 daily review and committed by 17:30 WAT by the engineering lead (plan §5, §15).

- **File name:** `daily/<YYYY-MM-DD>.md`, for example `daily/2026-10-12.md`.
- **Form:** copy [`../templates/daily-note.md`](../templates/daily-note.md). Fill it from that day's evidence only.
- A note is never written in advance or back-filled as if an event had happened.
- Any plan change made that day is named in the note (plan §19).
